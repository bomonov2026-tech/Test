## Muhim

- **Videoda subtitr yo'q** — ekranda faqat qisqa sarlavha.
- Roliklardagi ekranlar — **namuna (mockup)**, ilovaning haqiqiy skrinshoti emas.
  Namunalar kodga mos qilib chizilgan: nakrutka narxlari, eSIM raqami va SMS kodi,
  Prava savoli, reklama birjasining pul kafolati bosqichlari, reyting TOP-10 va h.k.
  Haqiqiy skrinshotlar yuborsangiz — o'shalar bilan almashtiraman.

## Qaysi birini birinchi joylash kerak

1. **04-prava** — eng keng auditoriya (har yili minglab odam prava oladi), bepul xizmat.
2. **09-reklama-birjasi** — «pul kafolati» kuchli hook, ishonch mavzusi.
3. **06-kanal-savdo-telegram** — «raqamlar soxta bo'lolmaydi» — raqobatchilarda yo'q afzallik.
4. **03-esim** va **02-nakrutka** — tez natija qidirayotganlar uchun.
5. **01-umumiy** — profil shapkasiga.
