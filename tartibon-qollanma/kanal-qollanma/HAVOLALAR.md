## Yaxshiroq variant: post tagida bosiladigan tugma

Telegram kanalda post tagida **tugma** chiqarish mumkin — havolani matn qilib
yozishdan ko'ra chiroyliroq va ko'proq bosiladi. Buning uchun postni **bot orqali**
yuborish kerak (qo'lda yuborilgan postga tugma qo'yib bo'lmaydi).

Botingiz orqali yuborish:

```
https://api.telegram.org/bot<TOKEN>/sendVideo
```

Yuboriladigan ma'lumot:

| Maydon | Qiymat |
|---|---|
| `chat_id` | kanalingiz, masalan `@TartibOn` |
| `video` | video fayl |
| `caption` | `kanal-postlari/<video>.txt` dagi matn (havola qatorisiz) |
| `parse_mode` | `HTML` |
| `reply_markup` | pastdagi JSON |

```json
{"inline_keyboard":[[{"text":"▶ Bo'limni ochish","url":"https://t.me/TartibOnBot?startapp=s_mykanal"}]]}
```

Har video uchun `url` ni yuqoridagi jadvaldan almashtirasiz.

> Tugma ishlatsangiz, `caption` dan oxirgi «👉 Bo'limni ochish: …» qatorini
> olib tashlang — aks holda havola ikki marta ko'rinadi.
